The single sentence that could have replaced an entire pointless meeting:

> We called this sync to confirm everyone is equally unprepared before we proceed with the wrong plan.

The hook: the meeting's secret purpose stated out loud — a sync whose only output is confirming collective unreadiness before proceeding with the wrong plan anyway.

## Run it

```sh
node main.ts
```

This validates the line (1–200 characters, a single line, no control characters) and writes it to `/output/entry.txt`.
